# 아이템은 어디서 얻나

섬 지도나 표시는 없다. 시작 위치(오두막 앞)에서 **흙길**을 따라가면 구역에 닿는다.

| 구역 | 가는 길 |
| --- | --- |
| 작은 숲 | 오두막 뒤(북쪽) 흙길 |
| 바닷가 | 오두막 앞(남쪽) 흙길 끝, 모래사장 |
| 꽃 언덕 | 북동쪽 흙길 끝, 섬에서 가장 높은 곳 |

- 기획서에는 바닷가는 병 2개, 꽃 언덕은 병 5개를 완성해야 열린다고 되어 있지만, **지금은 길이 막혀 있지 않아 처음부터 갈 수 있다.**
- 가방은 10칸이다. 줍는 재료는 가까이 가서 바라보면 "[E] ○○ 줍기"가 뜬다.

## 2. 바다와 관련된 아이템

| 아이템 | 어디서 | 상태 |
| --- | --- | --- |
| 조개껍데기 | 바닷가 모래사장 (맨손) | 얻을 수 있음 |
| 모래 | 바닷가 모래사장 (맨손) | 얻을 수 있음 |
| 조약돌 | 바닷가 (곡괭이, 지금은 줍기) | 얻을 수 있음 |
| 유목 | 바닷가 야자나무 근처 (도끼, 지금은 줍기) | 얻을 수 있음 |
| 종이배 | 우체통 상점에서 8코인 | 우체통을 만든 뒤 |
| 빈 병 | 매일 아침 파도에 떠밀려 와서 모래사장에 1개씩 놓임 (최대 3개) | 기획서 10단계, 아직 안 만듦 |

바다 모양 모델 중 **불가사리, 산호, 소라, 등대**는 `Assets/Models/Deco`에 있지만 아직 재료로 만들지 않아서 얻을 수 없다. 바닷가 재료(맨손으로 줍기)로 추가할 수 있다.

## 4. 우체통 상점에서 사는 소품 16종 (코인, 임시 가격)

우체통과 코인 시스템을 만든 뒤에 살 수 있다. 재료를 우체통에 넣어 팔면 다음 날 코인이 온다.

| 종이배 | 8 | 찻잔 | 10 |
| 별 장식 | 12 | 초승달 | 12 |
| 사다리 | 12 | 돌탑 | 14 |
| 이정표 | 15 | 우산 | 15 |
| 책 더미 | 18 | 캠프파이어 | 20 |

## 5. 팔 때 받는 코인 (임시)

기본 재료 1~3코인, 희귀 재료 20코인, 상점 소품 1~3코인.

값과 구역, 얻는 방법은 `Assets/Editor/MaterialSetup.cs` 표에서 고치고 메뉴 `유리병 정원 > 재료 데이터 만들기`를 누르면 바뀐다.
